# UMBRA GENETICS — Operations Terminal

A small, mobile-first fictional biotech operations terminal.

## Put these files in the same folder

- index.html
- style.css
- app.js
- bild11.png
- emblem.png (automatically cropped from bild11.png for the compact header)
- bip.mp3
- intro.mp3
- key1.mp3
- key2.mp3
- outro.mp3
- timer_complete.mp3

## Functions

- Countdown
- Stopwatch / elapsed timer
- Alarm
- Presets: 1 / 5 / 10 / 15 / 30 minutes
- Start / Pause / Reset
- System log
- Startup and shutdown audio
- Separate subtle keyboard sounds
- Countdown completion sound
- Harmless "SELF-DESTRUCTION SEQUENCE" joke

## Important

The app does not perform any destructive action. The self-destruction messages are only a visual/audio gag.

For GitHub Pages or another static host, upload the files together and open `index.html`.

Browser audio policies mean the INITIALIZE button is intentional: the first user interaction unlocks audio playback in most browsers.
